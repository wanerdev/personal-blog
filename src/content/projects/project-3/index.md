# Project Sombra - International Awning Installation

## Description
**Project Sombra** is a web platform developed for a company specializing in international awning installation. The solution includes a modern and optimized website, designed to offer a smooth and attractive user experience while showcasing the company's services and products.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend & Infrastructure:**
    - Server configuration
    - DNS management
    - Setup of development and production environments
    - Performance and security optimization

## Key Features
- Responsive design adaptable to all devices.
- Integration of contact and quotation forms.
- SEO optimization for better search engine ranking.
- Complete hosting and domain configuration.
- Implementation of security and performance best practices.
